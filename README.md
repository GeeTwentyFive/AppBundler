Program which takes in a path to a directory, a path from within the directory to an executable, and command line arguments for that executable, and creates a program which contains the contents of that directory within which, when run, unpacks that content into a temporary folder and runs the given program with the given command line arguments

# Usage
`AppBundler <PATH/TO/TARGET/DIR> <PATH/TO/APP/FROM/WITHIN> [ARGS...]`
